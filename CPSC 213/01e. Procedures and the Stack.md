## Implementing Procedure Return
- Return address is:
	- the address a procedure jump to when it completes
	- the address of the instruction following the call which made the procedure run
	- dynamic!

### Implementing Procedure Return cont'd

- so the caller must save it before the call is made

### Procedure Activation
- Activation: execution of a procedure
	- starts with procedure is called, ends when it returns
	- there can be multiple activations of a procedure that exist simultaneously
- Activation frame:
	- memory that stores activation's state
	- includes local variables and arguments
- we cannot be sure in general when or how many times a procedure will be activated, so these frames must be dynamically allocated
- should we allocate activation frames from the heap?
  - malloc to create frame
  - free to procedure return

### Properties of Activation frames
- order of frame allocation and deallocation is special
- freed in reverse order of allocation
- LIFO (STACK LFFFGG!!!!)
Simple Allocation for activation frames:
- reserve big chunk of memory for all frames
- initial address known
- simple, cheap (de)allocation: we simple add or subtract from a pointer

#### Procedure Prologue
- code that executes just before *"procedure"* starts
	- part in caller before call
	- part in callee at beginning of the call
	- generated by compiler for procedure call
- allocates activation frame and changes stack pointer
	- subtract frame size from stack pointer in r5
- possibly saves register values
- assigns values to allocated arguments

#### Procedure Epilogue
- code that executes just before *"procedure"* ends
	- part in callee before return
	- part in caller just after returning
- deallocates activation frame and restores stack pointer
	- we add the stack size of r5 back
- possibly restores saved register values

### Allocating and Deallocating Stack Frames: Cont'd
- **Caller prologue**
	- allocate space for arguments
	- save actual argument values to stack
- Callee prologue
	- allocate space for return address/local variables
	- save return address to stack
- Callee epilogue 
	- load return address from stack if stored there
	- deallocate space of return address/local variables
- caller epilogue
	- deallocate space of arguments
	- ~~gets return value from r0~~
