### Loops using Pointer Arithmetic
- alternative approach, keep a pointer (and not an index) of the current location
```C

	p = a;

		s += *p++
}
```
- s += \*p
- p++ (equivalent of above...)
- cannot use s = \*a++
- a is not an address, its literally 2
- deref? potential violation? definitely dont do this!

```C
void intcpy(int *s, int *d, int n) {
	for (int i = 0; i < n; i++) {
		d[i] = s[i]
	}
}

// using pointer arithmetic makes copying arrays wayyyy leaner
void intcpy(int *s, int *d, int n) {
	while (n--)
		*d++ = *s++
}
```

### Control Flow in the Machine
- program counter (PC)
	- special register that stores address of ***next* instruction** to execute
	- THE ***NEXT*** INSTRUCTION
- for sequential instructions, PC is updated in the fetch stage
	- increments by 2 or 6 depending on the size of our current instruction
- so, to implement a goto, all we need to do is change the PC

### Extending the ISA: Control Flow
- new instructions: jumps and conditional jumps
	- PC $\leftarrow$ address
	- PC $\leftarrow$ address if condition
- how do we evaluate conditions?
	- unconditional (we always jump)
	- conditional based on a ***register value***
		- common in RISC CPUs, used in SM 213
	- conditional based on result of last ALU instruction

#### Relative Addressing
- instead of specifying the destination address, specify the offset from current location
	- use current value of PC (address of next instruction) as base address
	- remember PC has been updated in fetch
- offset must be a signed number (since we can jump backwards)
- jumps using relative address are called branches
- Assembly still specifies actual **address/label**
	- converted to **offset** by assembler

### Implementing for loops
General form in both c and java is 
`for (<init>; <continue_condition>; <step>) <statement_block>`
- each of init, continue_condition, and step is optional or can be a compound expression
- for (;;) = while(true)
- for (int i=0, j=10; i <= j; i++, j--)

#### Pseudocode for loops
```asm
loop: goto end_loop if not <continue_condition>
		<statement_block>
		<step>
		goto loop
end_loop: # continue doing stuff or whatever
```

#### Example 1:
```C
for (i=0; i < 10; i++)
	s += a[i]
```
