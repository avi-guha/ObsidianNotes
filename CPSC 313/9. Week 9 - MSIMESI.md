### Big Picture
- each cache line is in some state for each cache though mos are invalid (containing no useful data)
- the metadata now contains a state:
	- one of MSI
	- provides more info than valid or dirty
	- need two bits to represent this

- a particular state is specifici to a paritucular line in a particular cache
	- the state of the cache line at 0xffff00 is unrelated to that of 0xc0aa00
	- the state of the cache line at 0xffff00 in core 1's l1 cache may differ from the state of the cache line at 0xffff00 in core 2's l1 cache
- each message sent includes an address index and tag bits and possibly more
- a cache operation can fetch data, set a cache line's state, evict a line and send invalidate requests to make other caches evict lines
	- *we can read from other caches too in reality to be faster, but we use the lower level as the "shared" memory as a source of truth for simplicity*

## Alternative: directory based coherence
- a centralized directory stores all state info
- processors consult before updating
	- information is similar to cach states
		- shared = one cache
		- uncached = 0
		- exclusive = 1
	- must also track which processors have the data
	- rather than broadcasting on the bus a core consults thedirectory and only sends messages to affected cores
