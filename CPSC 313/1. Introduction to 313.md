#### Part 2: Structures -- size and alignment

In this part, we will use types whose sizes are known a priori. For each structure below, identify where padding will be inserted to retain alignment of the structure. Then figure out the total size of the structure. Here is an example:

``` C
struct example {
       char c1;   // 1 
       uint32_t u32; // 4 to be aligned
       int64_t i64; // alreay aligned)
       char c2; // needs to be 8 byte aligned however. total 24 bytes
};
```

The uint32_t field must be 4-byte aligned, so insert 3 bytes of padding between the c1 field and the u32 field. The uint64_t field must be 8-byte aligned, but with the 3 byte padding, we are now 8-byte aligned (1 for the char, 3 padding, 4 for the uint32_t), so we do not need any more padding. However, the entire structure must have alignment of its largest alignment, which is 8, so we will need 7 more bytes after c2 to round the structure up to a multiple of 8. Therefore, the total size is 3*8 = 24 bytes.
