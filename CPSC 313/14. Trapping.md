- at startup the OS sets up a table, indexed by trap number, that contains address of code to be executed, whenever the trap occurs
	- points to library code/drivers
- (trap handlers)
	- once return will say to wakeup, INTERRUPT -> runs library code

## x86 trap handling
**Interrupt Descriptor Registers** (IDT): plays the role of the trap handler table
- special hardware: objects called gates
- gates provide access from lower privileged segments to higher privileged segments
	- when a low-privilege segment invokes a gate, it automatically arises the CPL (current privilege level) to the higher level
	- when returning from a gate, the CPL drops to its original level
		- when signal goes up it goes to higher privilege
- first 32 gates reserved for hardware defined traps
- remaining entries are available to software using the INT (interrupt) instruction

- Hardware register traditionally called PIC (programmable interrupt controller), then APIC, and now LAPIC (local advanced PIC, one per CPU in the system)
	- has wires to up to 16 devices
	- maps wires to particular locations in IDT
	- PIC sends the appropriate value for the interrupt handler dispatch to the processor
