   - (b) How many entries in the open file table have we added?

   - (c) How many entries in the vnode table have we added?

1. We have two file descriptors `fd3` and `fd4` pointing to two different open file table entries,
   and then we call `dup2(fd3, fd4)`.
   - (a) How many distinct file descriptors have we created?

still two

   - (b) How many entries in the open file table have we added/removed?

one was removed, only one left in the open file table

   - (c) How many entries in the vnode table have we added/removed?

removed one entry from vnode (unless other fds were pointing to it)

3. We call `fork()`, and then both processes call `open("hello.txt", ...)` independently on the same
   line of code.
   - (a) How many distinct file descriptors have we made?
two

   - (b) How many entries in the open file table have we added?

two
   - (c) How many entries in the vnode table have we added?
one
   - (d) How is this different from opening the file first, then forking the process?
the child process would inherit the fd

## Extra Practice: Implementing Pipe

In class, you learned how to redirect standard input/output to implement the shell's "`./cmd >
outputfile.txt`" behavior. In this exercise, let's try to implement something like "`./cmd1 |
./cmd2`" (this is called a pipe).
